# Computer Vision Lab — Fall 2026

Coursework from the Fall 2026 computer-vision lab at FAST NUCES.

This repository is an academic work log rather than a single production application. It contains focused exercises in image processing and computer-vision fundamentals, organized by lab session.

## Contents

- **Lab 01:** introductory image operations and pixel-level processing
- **Lab 02:** packaged task submissions
- **Lab 03:** filtering, transformations, compositing, and related exercises
- **Lab 05:** additional classical computer-vision tasks
- **Lab 06:** notebook-based lab work

## Running a task

Most exercises are standalone Python files. From the repository root:

```bash
python "Lab 01/Task 01.py"
```

Notebook work can be opened with Jupyter:

```bash
jupyter lab
```

## Notes

- Paths and required input images vary by exercise; inspect the selected task before running it.
- Generated images and notebook output are coursework artifacts.
- This repository is kept public to show progression and implementation practice, not as a reusable library.
